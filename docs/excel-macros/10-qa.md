# Q&A & Troubleshooting

## Common Questions

### Getting Started

??? question "I don't see the Developer tab!"
    **Solution:**
    
    **Windows Excel:**
    1. File → Options → Customise Ribbon
    2. Tick the "Developer" checkbox on the right
    3. Click OK
    
    **Mac Excel:**
    1. Excel menu → Preferences → Ribbon & Toolbar
    2. Tick "Developer" in the list
    3. Click Save

??? question "When I try to run a macro, nothing happens"
    **Check:**
    
    1. **Macro security setting**
       - Developer → Macro Security
       - Should be "Disable all macros with notification"
       - Did you click "Enable Content" yellow bar after opening the file?
    
    2. **File format**
       - Is your file saved as `.xlsm`? (Macros don't work in `.xlsx`)
       - File → Save As → Choose "Excel Macro-Enabled Workbook (.xlsm)"
    
    3. **Macro exists**
       - Alt+F8 → Do you see your macro in the list?
       - If not, it wasn't saved properly

??? question "Can I use macros on Excel Online / Web?"
    **Short answer:** No, not VBA macros.
    
    **Long answer:** 
    - VBA macros only work in **desktop Excel** (Windows/Mac)
    - Excel Online supports **Office Scripts** (different technology)
    - If you need web-based automation, explore Office Scripts or Power Automate
    
    **For this tutorial:** Use desktop Excel

??? question "Will macros work on my colleague's computer?"
    **Yes, if:**
    - You send them the `.xlsm` file (macros embedded)
    - They have desktop Excel (Windows or Mac)
    - They enable macros when opening (yellow security bar)
    
    **No, if:**
    - You saved macros in "Personal Macro Workbook" (those stay on your computer)
    - You only send the data as `.xlsx` (macros stripped out)

### Recording & Running

??? question "Why does my macro select the wrong cells?"
    **Cause:** You recorded absolute references (specific cells like A1, B5)
    
    **Example problem:**
    You recorded the macro on Row 2, but now your data is on Row 10, and the macro still targets Row 2!
    
    **Solution:**
    Edit the macro to use **dynamic ranges**:
    
    ```vba
    ' ❌ Hard-coded (breaks easily)
    Range("A1:D100").Select
    
    ' ✅ Dynamic (finds last row)
    Dim lastRow As Long
    lastRow = Cells(Rows.Count, "A").End(xlUp).Row
    Range("A1:D" & lastRow).Select
    ```

??? question "My recorded macro is huge (1000+ lines)!"
    **Cause:** The recorder captures *every little action*:
    - Mouse clicks
    - Scrolling
    - Selecting and reselecting
    
    **Solution:**
    1. Delete unnecessary lines (anything with just `.Select`)
    2. Combine repeated actions with loops
    3. Next time: Plan your recording - do each action once, deliberately

??? question "Can I record a macro across multiple sheets?"
    **Yes!** While recording:
    1. Click on Sheet2
    2. Do your actions
    3. Click on Sheet3
    4. Do more actions
    5. Stop recording
    
    The macro will replay exactly which sheets you visited.

??? question "Ctrl+Z doesn't undo my macro!"
    **This is normal!** VBA macros often clear Excel's undo history.
    
    **Safety protocol:**
    - Always save before testing (`Ctrl+S`)
    - Test on dummy data, never your only copy
    - If something goes wrong: Close without saving and reopen
    
    See [Safety section](09-tips-best-practices.md#safety-error-handling) for details.

### Editing & Debugging

??? question "I get a syntax error when running my macro"
    **Common causes:**
    
    1. **Missing quotes around text**
       ```vba
       ' ❌ Wrong
       Range("A1").Value = Hello
       
       ' ✅ Correct
       Range("A1").Value = "Hello"
       ```
    
    2. **Missing End statement**
       ```vba
       ' ❌ Wrong - no End If
       If x > 10 Then
           MsgBox "Large"
       
       ' ✅ Correct
       If x > 10 Then
           MsgBox "Large"
       End If
       ```
    
    3. **Typo in keyword**
       ```vba
       ' ❌ Wrong - "Renge"
       Renge("A1").Value = 10
       
       ' ✅ Correct
       Range("A1").Value = 10
       ```

??? question "How do I view/edit the code of a recorded macro?"
    **Method 1:**
    1. Alt+F11 (opens VBA Editor)
    2. Double-click Module1 in left panel
    3. Code appears!
    
    **Method 2:**
    1. Developer → Macros (or Alt+F8)
    2. Select your macro
    3. Click "Edit"

??? question "Can I delete a macro?"
    **Yes!**
    
    **Method 1: From Excel**
    1. Developer → Macros (Alt+F8)
    2. Select the macro
    3. Click "Delete"
    
    **Method 2: From VBA Editor**
    1. Alt+F11
    2. Find the macro code
    3. Select all the code (from `Sub` to `End Sub`)
    4. Press Delete

??? question "How do I test just part of my macro?"
    **Method 1: Comment out lines**
    Add `'` at the start of lines you want to skip:
    
    ```vba
    Sub TestMacro()
        Range("A1").Value = "Hello"
        ' Range("B1").Value = "World"  ' Commented out
        ' MsgBox "Done"                 ' Commented out
    End Sub
    ```
    
    **Method 2: Use breakpoints**
    1. Open VBA Editor (Alt+F11)
    2. Click in grey left margin (red dot appears)
    3. Run macro - it stops at the breakpoint
    4. Press F8 to step through line-by-line

### Errors & Troubleshooting

??? question "Error: Run-time error 9: Subscript out of range"
    **Meaning:** Trying to access something that doesn't exist
    
    **Common causes:**
    1. Sheet name spelled wrong (case-sensitive!)
       ```vba
       ' If sheet is named "Specimen_1"
       Set ws = Worksheets("specimen_1")  ' ❌ Wrong case!
       Set ws = Worksheets("Specimen_1")  ' ✅ Correct
       ```
    
    2. Sheet doesn't exist
       ```vba
       ' Add error handling:
       On Error Resume Next
       Set ws = Worksheets("SheetName")
       If ws Is Nothing Then
           MsgBox "Sheet not found!"
           Exit Sub
       End If
       On Error GoTo 0
       ```

??? question "Error: Run-time error 1004"
    **Meaning:** Excel can't do what you asked
    
    **Common causes:**
    
    1. **Invalid range**
       ```vba
       ' ❌ Row 1048577 doesn't exist (Excel max is 1048576)
       Range("A1048577").Value = 10
       ```
    
    2. **Chart/object already exists**
       ```vba
       ' ✅ Delete old chart first:
       On Error Resume Next
       ActiveSheet.ChartObjects("MyChart").Delete
       On Error GoTo 0
       ```
    
    3. **Protected sheet**
       - Unprotect the sheet first
       - Review → Unprotect Sheet

??? question "Error: Type mismatch"
    **Meaning:** Wrong data type
    
    **Example:**
    ```vba
    Dim age As Integer
    age = "Twenty"  ' ❌ Can't put text in integer variable!
    ```
    
    **Fix:** Check variable types match data
    
    ```vba
    ' If cell might contain text, use Variant:
    Dim value As Variant
    value = Range("A1").Value  ' Works for number or text
    
    If IsNumeric(value) Then
        ' It's a number, safe to calculate
    Else
        MsgBox "Not a number!"
    End If
    ```

??? question "My macro runs but does nothing / does the wrong thing"
    **Debugging strategy:**
    
    1. **Add Debug.Print statements**
       ```vba
       Sub TestMacro()
           Dim lastRow As Long
           lastRow = Cells(Rows.Count, "A").End(xlUp).Row
           Debug.Print "Last row is: " & lastRow  ' Check value!
           
           ' More code...
       End Sub
       ```
       
       View output: Ctrl+G in VBA Editor
    
    2. **Step through with F8**
       - Alt+F11 → Click in your macro → Press F8
       - Watch Excel window after each line
       - Identifies exactly where behaviour is wrong
    
    3. **Check sheet references**
       ```vba
       ' Are you on the right sheet?
       Debug.Print "Active sheet: " & ActiveSheet.Name
       ```

### Performance

??? question "My macro takes forever to run!"
    **Solutions (in order of impact):**
    
    **1. Turn off screen updating (biggest impact):**
    ```vba
    Application.ScreenUpdating = False
    ' Your code
    Application.ScreenUpdating = True
    ```
    
    **2. Remove .Select statements:**
    ```vba
    ' ❌ Slow
    Range("A1").Select
    Selection.Value = 10
    
    ' ✅ Fast
    Range("A1").Value = 10
    ```
    
    **3. Use arrays for large data:**
    ```vba
    ' Read 1000 cells at once instead of 1 by 1
    Dim arr As Variant
    arr = Range("A1:A1000").Value
    ```
    
    See [Performance Optimization](09-tips-best-practices.md#performance-optimization) for details.

??? question "Excel freezes when running my macro"
    **Cause:** Infinite loop or very long process
    
    **Emergency stop:** Press **Esc** or **Ctrl+Break**
    
    **Prevention:**
    ```vba
    ' Add this in long loops to allow user to cancel
    For i = 1 To 100000
        DoEvents  ' Allows Ctrl+Break to work
        ' Your code
    Next i
    ```

### Advanced Topics

??? question "Can macros write formulas?"
    **Yes!**
    
    ```vba
    ' Write formula
    Range("E1").Formula = "=B1*C1"
    
    ' Write formula with absolute references
    Range("E1").Formula = "=$B$1*$C$1"
    
    ' Write formula that references other sheets
    Range("E1").Formula = "=Sheet2!A1*2"
    ```
    
    **Tip:** Use `.Formula` for English formulas. If Excel is non-English, use `.FormulaLocal`.

??? question "Can I password-protect my VBA code?"
    **Yes!**
    
    1. Alt+F11 (VBA Editor)
    2. Tools → VBAProject Properties
    3. "Protection" tab
    4. Tick "Lock project for viewing"
    5. Enter password
    6. Click OK
    
    **Warning:** VBA password protection is weak - it can be cracked. Don't rely on it for security!

??? question "How do I share macros with my team?"
    **Option 1: Embed in workbook (easiest)**
    - Save macros in "This Workbook" when recording
    - Send the `.xlsm` file
    - Recipients click "Enable Content" to use macros
    
    **Option 2: Export as .bas file**
    1. Alt+F11 → Right-click Module1 → Export File
    2. Save as `MyMacros.bas`
    3. Share this file
    4. Recipients: Alt+F11 → File → Import → Choose `.bas` file
    
    **Option 3: Personal Macro Workbook (for frequent use)**
    - Macros saved here load automatically when Excel opens
    - But: Only available on YOUR computer
    - Use for personal productivity macros

??? question "Can macros interact with other programs?"
    **Yes!** VBA can control:
    
    - **PowerPoint** - Create presentations, add slides, paste charts
    - **Word** - Generate reports, fill templates
    - **Outlook** - Send emails with attachments
    - **File system** - Copy/move/delete files
    - **Databases** - Read from Access, SQL Server
    
    **Example: Send email**
    ```vba
    Dim OutApp As Object, OutMail As Object
    Set OutApp = CreateObject("Outlook.Application")
    Set OutMail = OutApp.CreateItem(0)
    
    With OutMail
        .To = "colleague@example.com"
        .Subject = "Experiment Results"
        .Body = "Please see attached."
        .Attachments.Add "C:\Results.xlsx"
        .Send
    End With
    ```
